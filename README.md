# Payyo

Landing page do Payyo — pagamentos em lote via PIX pela API do Inter.

Site estático, sem build. `index.html` na raiz + imagens em `assets/`.

## Rodar local

Abra `index.html` no navegador, ou sirva a pasta com qualquer servidor estático:

```
npx serve .
```

## Deploy

GitHub Pages a partir da branch `main`, pasta raiz (`/`).
